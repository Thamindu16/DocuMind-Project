TechNova Solutions - IT Security and Acceptable Use Policy

1. Password Management
All employees must use the company-provided password manager (TechNova Vault). Passwords must be at least 12 characters long and include a mix of uppercase, lowercase, numbers, and symbols. Passwords must be rotated every 90 days. Using the same password for multiple services is strictly prohibited. Multi-Factor Authentication (MFA) is mandatory for all company accounts.

2. VPN and Network Access
Accessing company internal systems from outside the office requires a secure VPN connection (TechNova VPN). Public Wi-Fi networks (e.g., coffee shops, airports) must never be used without an active VPN. Employees are prohibited from connecting unauthorized personal devices to the internal office network.

3. Software Installation
Employees are not allowed to install unauthorized third-party software on company laptops. All software requests must go through the IT Helpdesk. Open-source software is permitted only after a security review. Pirated software is strictly banned.

4. Data Protection and BYOD
Company data must only be stored on approved cloud platforms (Google Workspace or AWS). Downloading sensitive client data to personal devices is a violation of policy. If a company laptop is lost or stolen, the employee must report it to IT Security within 2 hours.
