# DocuMind

Ask a question about the company's HR or IT policies and DocuMind answers it from the actual documents, then tells you which file the answer came from.

If the answer isn't in the documents, it just says so. It won't make one up.

You can try something like:

- How many days of annual leave do I get?
- What's the password policy?
- If I take 9 days of leave, how many do I have left?

Made by Thamindu as a learning project on retrieval-augmented generation.
