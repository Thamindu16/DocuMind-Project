# DocuMind

Ask a question about the company's HR, IT, benefits or support policies and DocuMind answers it from the actual documents, then tells you which file the answer came from.

You can chat with it normally, ask follow-up questions, and write in English or Sinhala. If the answer isn't in the documents, it just says so. It won't make one up.

You can also attach your own PDF or text file with the paperclip button, wait for the "ready" message, and then ask questions about it.

Made by Thamindu as a learning project on retrieval-augmented generation.
